# Spec 013 — أدوات خلف حساب + حذف التفريغ + جولة التصميم

**المصدر**: ملاحظات المستخدم الحية على الموقع (2026-11-07). قرار نهائي: **لا شيء بلا حساب**.

## User Stories

- **US1**: زائر لا يصل إلى أي أداة؛ كل الأدوات داخل المساحة المسجّلة فقط.
- **US2**: أداة «التفريغ الصوتي» محذوفة نهائيًا من كل المستودع (واجهة/API/نصوص/توثيق).
- **US3**: التشكيل أداة داخلية لمسجّل فقط، بسيطة ومتزامنة (نص → نص).
- **US4**: صفحة الهبوط ممتلئة، لا تبدو مولّدة بالـAI، والنصوص صادقة: بلا «أول منصة شاملة للثانوية الأزهرية» (هذه دعوة جهة أخرى؛ نحن ذراع المستندات ضمن منظومة ابن الأزهر).
- **US5**: لا تُفقد حالة أثناء التنقل: تقدم الرفع لا يرتد، المعالجة لا تعرض فراغًا، الحذف لا يُبقي الملف، والعودة للصفحة تستعيد الجاري.
- **US6**: أيقونة الموقع (favicon) تظهر في تبويب المتصفح على نسخة HF.

## Requirements (FR)

- **FR-001**: لا يوجد `/tools` عام ولا `/api/tools/guest/*`؛ middleware يساوي `/tools*` بالمسارات المحمية (تحويل لتسجيل الدخول)، وsitemap بلا روابط أدوات.
- **FR-002**: حذف `transcription` من: pages/`tools/transcription`، messages (ar/en)، services، API، pipeline exports، tests، docs. يبقى OCR/المعالجة كجزء من مسار المستندات.
- **FR-003**: أداة تشكيل داخلية `POST /api/tools/tashkeel` (جلسة مطلوبة، حد نص 20k، synchronous) + صفحة `/dashboard/tools` بواجهة نتيجة تعرض/تنسخ/تنزيل .txt.
- **FR-004**: messages: حذف keys أدوات الضيوف و`tools.upcoming.items.transcription`؛ `section.hero.eyebrow` و`footer.tagline` بلا superlative كاذب؛ وسم «منصة ابن الأزهر» صحيح همزة/تاءً.
- **FR-005**: شريط تقدم علوي عند التنقل بين الصفحات + skeletons لصفحة الملفات/المجلدات (loading.tsx فعّال).
- **FR-006**: monotonic clamp لتقدم الرفع (لا يرجع 25%→0 إلا بدء جديد per jobId).
- **FR-007**: صفحة المعالجة: رقائق مراحل عربية حقيقية + «جارٍ التجهيز» بدل الفراغ + polling fallback عند صمت SSE، واستعادة jobId عند العودة.
- **FR-008**: الملفات المحذوفة (soft-delete) لا تُعرض ولا تطلب «تحليل الصفحات».
- **FR-009**: سكربت sync HF يشمل `apps/web/public` (favicon PNGs) — يُثبت حيًا بـcurl بعد النشر.
- **FR-010**: الفاتح سليم (tokens لا ألوان صلبة)، ولا ميزات AI-LOOK: لا gradient text، لا eyebrow micro-labels فوق العناوين، لا ومضات/زخارف مولّدة.
- **FR-011**: `pnpm check` + build + unit tests خضراء؛ بوابة spec_gate لـ013 نظيفة.

## Non-goals

- لا تغيير في مسار OCR الأساسي ولا تصدير DOCX. الأيقونات الحالية تبقى كما هي (طلب مستخدم صريح).
